Covers

Playlists that mirror a real Yoto card keep that card's artwork as cover.jpg, pulled from the product page. Upload it as the playlist image when you create the Make Your Own card, and it looks the same on the player.

  • It's the publisher's artwork, so it's for your own card — don't redistribute it.
  • cantonese-nursery-rhymes uses Yoto's Nursery Rhymes art as a thematic stand-in; no Cantonese card exists.
  • speech-therapy-english uses Ms. Rachel's I'm So Happy art — the closest Yoto card to the theme, since her show began as a speech-and-language resource.
  • speech-therapy-cantonese uses Yoto's Animal Sounds art; animal sounds are the first thing a late talker imitates.
  • The eight target cards use eight different Super Simple characters, one per card, so no two covers repeat: the Roundabouts pig (animals), the yellow Noodle & Pals friend (actions), a Bumble Num (food), Carl's Rescue Crew (routines), a Rhymington Square monster (social), Lulu the Owl (feelings), the Peekaboo cat (Cantonese animals) and a Roundabouts penguin (Cantonese routines). Each sits in its own painted scene — meadow, sunburst, kitchen, morning sky, party wall, sand rings, garden, night sky — with its own title colour, so no two read as the same template. The characters are Super Simple's; the backgrounds were painted for these cards.
  • super-simple-favourites has a custom cover: Super Simple's own Noodle artwork, cream background, hand-lettered title.

Custom covers are built with the yoto-cover skill — .opencode/skills/yoto-cover/ holds the house style (1200×1902, cream #FFFFE8, Yoto blue #0392D4, one character, no scenery) and scripts/make_cover.py, which keys the art, composes the card and sets the title. Ask for a cover and it runs automatically.

Adding a playlist

Send a YouTube link — a playlist, a single video, or a card you've seen. I'll add playlists/<name>/reference.md with the tracks pulled out, in order, each with its link, and notes on anything swapped or missing.

Printing the covers

Every card has one image: playlists/<name>/cover.jpg at 638 × 1011 px, 300 DPI — 54 × 85.6 mm, the size of a Yoto card. That same file is what the app accepts and what the print sheets embed. print/ holds A4 / US Letter sheets with nine labels each and crop marks. Print at 100% / Actual size — never "fit to page". Rebuild with:

bash python3 .opencode/print/build_print.py

See print/README.md for paper and trimming notes.

Browsing it as a website

docs/ is a generated static site: the ranked shelf, one page per playlist with clickable links and covers, plus the ranking and this readme. Rebuild after editing any markdown:

bash python3 .opencode/site/build.py

To publish on GitHub Pages: push the repo, then Settings → Pages → Deploy from a branch → main / /docs. The site works from a subpath, so https://<user>.github.io/<repo>/ is fine.

Using a playlist

  1. Open its reference.md and listen through the links.
  2. Put the audio on a Make Your Own playlist at yotoplay.com (Make Your Own → create playlist).
  3. Link the blank card: Yoto app → Players → your player → Link a card, then hold the card flat on the player's NFC spot until it beeps.
